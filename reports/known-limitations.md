# 已知限制（2026-09-14）

## 算法

- 零训练约束：YOLO11n COCO 通用权重 + MediaPipe Pose Full 原样使用，未做任何网球域微调。
  小球（<10px）与运动模糊是漏检主因；conf 与规则分数不是准确率。
- 球召回第一轮目标（70%/90%）尚未在人工标注片段上验证——完整真值标注未完成，算法目标状态
  为 not_measured，不以覆盖率冒充召回。
- 切片2 类“极小球”视频需 4×3 以上分块（有效分辨率 ~2.4×）才有可用覆盖，代价是耗时显著上升；
  专用网球检测器接入（§五D）尚未启动。
- 人物为单目标：多人交叉遮挡后无法可靠关联时会保持“目标丢失”而非猜测；长丢失后唯一合理候选
  重锁是低置信规则，可被人工复核推翻。
- 正反手规则依赖默认背面拍摄视角；其他视角证据不足时输出 unknown。
- 撞墙候选依赖用户墙面四点；切片2/5 分析未设置墙面，故 wall_contact_candidate 为 0。

## 测量

- 速度单位为 px/s（图像平面，同机位参考）；km/h 恒为 null 且给出原因。
- “球观测覆盖”是检测覆盖率，不是召回/精确率；召回仅在人工标注可见帧上定义。

## 工程

- PyAV 与 OpenCV 各自携带 FFmpeg 动态库，macOS 打印重复 AVFoundation 类警告；未观察到失败。
- 分析为单任务离线执行：1080p59 全片 tiled_local 约 3.3–6.6× 实时（负载相关），不是实时系统。
- observations API 单窗 1800 帧上限；前端分窗加载。
- 标注模式进入后视频从头播放（待改进）；评估链路已验证但完整真值集待用户标注。
- 本轮浏览器验证覆盖主要路径；未做长时热稳定、冷启动对照与取消恢复的系统性压力测试。
