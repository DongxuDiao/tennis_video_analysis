# 训练视频 UX 简化（2026-09-16）

依据用户指定的 https://github.com/nextlevelbuilder/ui-ux-pro-max-skill ，读取 SKILL、pro-rules 并检索 design-system 和错误恢复建议。体育营销模板不适用于训练工具，采用 Flat Design 的轻量布局，遵循用户既有偏好使用蓝色主操作、红色删除；系统中文字体、本地资源，无在线字体依赖。

## 日常流程
上传 → 后台准备并自动排队分析 → 回看标注视频/原视频 → 点击击球候选跳转 → 下载视频/报告。
模型与参数由既有自动管线决定，不展示方法选择、持拍手、版本列表、逐帧 JSON、环境页或人工校准。旧页面源码保留在 DeveloperApp.tsx 等文件，未在默认入口加载。

- 新前端上传显式提交 auto_analyze=true，旧 API 客户端默认维持仅导入行为。
- worker 成功准备后在数据库内排队 automatic，使用 import job ID 保证幂等，不依赖页面定时器。
- 视频长度限制 60 秒；准备失败不排队分析。分析失败保留原视频与历史成功结果，可重试。
- 不声称识别覆盖率等于准确率；缺失轨迹不伪造成测量，未标定不显示真实速度/落点。
- 删除先进入回收站；恢复及永久删除仅在回收站显示，永久删除明确确认。
- 原生 dialog 支持焦点约束及 Esc；44px 操作目标、键盘焦点、减少动画偏好、375px 单列布局。

## 验证
前端 TypeScript + Vite 构建通过；后端 45 项测试通过，其中新增导入成功接续、重复执行幂等与导入失败不排队测试。浏览器验证既有真实视频正常播放、候选片段跳转、原视频对照和手机无横向溢出。

本次是交互及工作流调整，未训练或更换识别模型，不将界面改进描述成识别精度提升。
