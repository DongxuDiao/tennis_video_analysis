# 给开发 Agent 的启动任务

请读取同目录《网球训练分析工具_V1实施方案.md》，将其作为本次产品需求与验收任务书，完成一个真实可用的本地首版。请实际实现和验证，不只返回设计方案。

用户设备是 MacBook Air M2（2022），16GB 统一内存。目标是导入单人对墙网球训练视频，以现成预训练小模型离线分析，提供可调试、可复核的 React 前端。首版不训练、不微调、不依赖云推理。

先读取目标仓库的 AGENTS.md、PROJECT.md、README，检查现有结构并保留用户改动；没有现有代码时按任务书建立项目。默认 React + TypeScript + Vite、FastAPI、SQLite、独立单 worker、YOLO11n、MediaPipe Pose Full、FFmpeg/PyAV/OpenCV。对依赖版本先做 Apple Silicon 兼容性验证，再锁定。

必须跑通以下闭环：

1. 前端导入 MP4/MOV，准备可播放代理，查看元信息并选择分析片段。
2. 配置持拍手、球搜索 ROI、墙面区域及可选标定；创建持久化 run。
3. 实际运行预训练模型，生成姿态、球候选和追踪，提取击球/撞墙候选、正反手或 unknown。
4. 前端同步视频图层，逐帧检查候选、断轨、事件依据；统计可跳回证据。
5. 人工新增、改正、排除事件及点位，支持撤销和刷新恢复；自动结果不可变。
6. 修改参数创建新 run，前端 A/B 对比；人工辅助的派生结果明确标为 assisted。
7. 导出冻结 revision 的 MP4、CSV、JSON，保证与前端选择的结果视图一致。
8. 提供独立人工标注模式和自动结果评分；记录样本、分母、事件一对一匹配及失败样例。

按任务书 M0–M5 推进。优先交付真实模型到前端的纵向闭环，再完善事件、复核、对照及导出。不要先做一个使用随机检测结果的漂亮仪表盘。

重要约束：

- 检测不到必须显示未知/丢失，预测点与真实观测分开，不能用长插值虚构轨迹。
- 物理 km/h 首版保持不可用；仅提供明确标为 px/s 的图像速度。墙面四点映射不能用作空中三维测速。
- confidence 和规则分数不等于准确率；不沿用之前对话中未实测的百分比及处理速度预估。
- 真正可用需要浏览器实际操作验证；只有 build/test 成功不算完成。
- 单重任务并发，流式解码，结果分块落盘，MPS 失败可明确回退 CPU，任务支持取消及崩溃恢复。
- 首次依赖和官方模型准备完成后，应能离线使用。不要购买资源、上传用户视频到第三方、启动训练或发布到互联网。

当前没有用户未加工的原始视频文件。先完成应用与工程测试；有合适来源的公开未加工样本可用于真实 smoke test。没有真实样本时仍要交付可运行应用、清楚标记的合成工程测试和待验收项，不得把参考小红书中已叠加图层的视频或合成素材当作准确率证明。真实素材到位后应能直接从前端跑验证。

交付源代码、锁定依赖、启动脚本、中文 README、validation.md、performance.json、known-limitations.md、实际浏览器验证证据及导出样例。最终分别报告“工程闭环”“算法目标”“M2 目标设备实测”的状态与证据，缺测就写缺测。

如果代码目录已经明确，直接在那里实施；如处于全新空目录，可在当前目录下建立 tennis-agent 子目录。按现有授权完成本地实现与验证，外部发布和付费动作另行确认。
