# 运动视频动作分析：外部视觉执行规范 v1

这是默认 sports-video-motion-analysis 技能在“只用外部模型、没有本地计算工具”条件下的执行版。只使用输入图片的证据，不声称执行原技能中的 Python 脚本、音频检测、标定、物理求解或人工验证。

1. 先检查视角：固定/移动机位、裁剪/竖屏、人数、遮挡和球的可见程度。视角变化与远端低分辨率会降低可信度，在观察说明中写清。仅有少量时刻时，不猜测整段视频的机位稳定性。
2. 人物用近端/远端或画面位置称谓，不辨认身份。分别定位可见人物，不混用不同球员的动作；疑似击球必须能归属人物，否则说明歧义。
3. 球点必须来自当前帧可见球或明确拖影，无法分辨则留空。不能把球拍、场地线、静止杂物当球。不能用理想弹道或颜色猜点补缺口。
4. 连续图片仅帮助判断时序，不代表覆盖了中间帧。音频冲击、击球精确时刻、逐拍总数未经确认；hit 只是抽样时刻附近的候选，不把漏采片段当作没有击球。
5. 动作名称受持拍手与朝向共同影响，不能把画面左右直接等同正反手。没有几何验证时保留未知，只描述可见的准备、挥拍、触球位置和随挥证据。
6. 单机位投影不能直接测量三维关节角。可谨慎比较同一人的可见姿态变化，不能把投影差写成真实角度或精确百分比。
7. 没有可信场地标定、独立尺度和逐帧观测时，真实球速、三维接触点与落点均不可测。不可测不记为 0，不输出平均或最大速度。
8. 落点、出界与下网必须有直接可见证据；未覆盖落地时刻则未判定。回合结果与球员击球统计不混用分母，不声称生成已验证的落点图。
9. 报告观察与推测分开，先写可见事实及限制，再给有这些事实支持的训练建议；对遮挡、模糊、归属不明应保留未知。禁止复用原技能示例中的测量数值、准确率或比赛结论。
10. 坐标必须对应所给帧图像，保持帧号与时间一致。不能把相邻帧位置挪到当前帧。输出只使用本次 JSON 协议，不执行命令、不发布飞书文档、不访问链接。
